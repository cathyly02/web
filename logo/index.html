One line, one bunny.

Rabbits have always been my thing, so I wanted my logo to feel like me: soft, a little playful, and approachable. The rabbit is drawn in a single continuous line, and its long, floppy ear wraps around my name like it's giving it a hug.

I paired the line with Happy Monkey, a rounded typeface whose stroke weight matches the drawing, so the illustration and the wordmark read as one piece. The raspberry accent is bold enough to hold up at small sizes while still feeling warm.

Logo Versions

Black & White

The primary one-color version. Use it for print, documents, and anywhere color isn't available.

Color

The main version for my portfolio and the web. The rabbit is raspberry and the name stays charcoal so it's easy to read.

Reverse

White on dark. Use it for dark mode, dark photos, and dark backgrounds.

Favicon

Only the rabbit, cropped so it peeks into the frame. The name is dropped because it can't be read at tab size. The white rounded tile keeps it visible on both light and dark tabs.

Usage & Sizing

Sizes

  • Full logo minimum: 160px wide (digital) / 1.25in (print)
  • Nav bar: 160–200px wide
  • Hero / cover: 400px+ wide
  • Favicon: 16, 32, and 64px

Clear Space

Leave empty space around the logo equal to the height of the "C" in "Cathy" on every side.

Do & Don't

  • Use the reverse version on dark backgrounds
  • Scale proportionally
  • Stretch, skew, or rotate the logo
  • Recolor it outside the brand palette
  • Put the color version on busy photos
  • Use the full logo below 160px; use the favicon mark instead
